    Language Support Tables¶

    In a nutshell

    The per-language STT/TTS/parser coverage tables for OVOS: which languages have a bundled offline speech model, and which have a number/date parser module. Use it to look up one language. For the narrative on how language support works and how to improve it, see Language Support.

    Supported Languages¶

    ovos-config autoconfigure reads the recommendation files in the recommends/ directory of your installed ovos-config. These files are the authoritative list. The tables below show what each release channel ships.

    Stable channel¶

    The stable channel installs ovos-config 1.2.2. It recommends offline speech recognition for 11 languages: ca-es, da-dk, de-de, en-us, es-es, eu-es, fr-fr, gl-es, it-it, nl-nl and pt-pt. It has no --gpu tier.

    Offline STT plugin Languages
    ovos-stt-plugin-citrinet ca-es, de-de, fr-fr, it-it, nl-nl
    ovos-stt-plugin-fasterwhisper da-dk, en-us, pt-pt
    ovos-stt-plugin-fasterwhisper-zuazo es-es, eu-es, gl-es

    Testing channel¶

    The testing channel installs ovos-config 2.1.1. It covers the same 11 languages and adds a --gpu tier.

    Tier STT plugin Languages
    Offline ovos-stt-plugin-citrinet ca-es, de-de, en-us, es-es, fr-fr, it-it, nl-nl, pt-pt
    Offline ovos-stt-plugin-fasterwhisper da-dk, eu-es, gl-es
    GPU ovos-stt-plugin-fasterwhisper every language except eu-es
    GPU ovos-stt-plugin-HiTZ eu-es

    Alpha channel¶

    Alpha channel only

    The alpha ovos-config recommends offline speech recognition for 69 languages and a GPU tier for 60. Both tiers use ovos-stt-plugin-onnx-asr, one plugin that runs every model architecture in the table.

    int8 next to a model means the recommendation uses a quantized CPU build. The GPU tier sets use_cuda: true.

    Where the table shows offline TTS voices, the recommendation is ovos-tts-plugin-phoonnx with one pinned voice for each gender listed. A single-speaker Facebook MMS voice counts as male. autoconfigure adds a voice only when its gender is known.

    "none" means the release has no recommendation for that tier. autoconfigure skips that part of the configuration and tells you so. Use an online STT plugin, or configure a multilingual model by hand, for example ovos-stt-plugin-server pointed at a self-hosted STT server.

    A language that is in neither table has no bundled recommendation. Thai is one example: ovos-config ships no th-* recommendation file, so autoconfigure -l th-th has nothing to select. Configure Thai by hand until somebody contributes a recommendation.

    Per-language status matrix¶

    The STT and TTS columns summarize the alpha-channel table above. "yes" means a bundled offline recommendation exists for at least one voice or gender. "partial" means only some of it exists. "no" means the release has no bundled offline recommendation.

    Number and date parsing come from the language modules actually shipped in the installed ovos-number-parser / ovos-date-parser. A yes here means a dedicated language module exists (numbers_<code>.py / dates_<code>.py), not that every phrasing is covered.

    This matrix tracks the original, longest-supported languages. See the Supported Languages table above for the full, larger set of languages with a bundled offline STT and/or TTS recommendation.

    Language Offline STT Offline TTS Number parser Date parser
    en-US yes yes yes yes
    en-GB no yes yes yes
    en-AU no no yes yes
    de-DE yes yes yes yes
    fr-FR yes yes yes yes
    es-ES yes yes yes yes
    it-IT yes yes yes yes
    nl-NL yes yes yes yes
    pt-PT yes yes yes yes
    pt-BR no yes yes yes
    ca-ES yes yes yes yes
    gl-ES yes yes yes yes
    eu-ES yes yes yes yes
    da-DK yes partial (male only) yes yes

    Both the number and date parsers cover far more languages than this original matrix, including several with no offline STT or TTS recommendation, for example Hebrew and Turkish. Adding a language module for parsing text is much cheaper than shipping a full speech model, so this column tends to run ahead of STT/TTS.

    pt-BR has no bundled offline STT

    Brazilian Portuguese has no bundled offline CPU speech-to-text recommendation. ovos-config autoconfigure -l pt-br --offline skips STT. On the alpha channel, --gpu recommends a Whisper model for pt-br. Without a GPU, use an online STT plugin, or configure a multilingual offline model by hand.

    A language can have speech support and no parser module. Japanese is one example. The alpha ovos-config recommends offline STT and TTS for ja-jp, but ovos-number-parser and ovos-date-parser have no Japanese module. Spoken numbers and dates in Japanese are not parsed until somebody contributes one.
